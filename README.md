# DAMADICS Benchmark – Subset for Research Reproducibility

This repository contains a subset of the DAMADICS benchmark dataset used in the study:

"Unsupervised and Explainable Fault Diagnosis on Industrial Actuators: A Hybrid Approach to Feature Extraction and Causal Analysis"

The DAMADICS benchmark (Development and Application of Methods for Actuator Diagnosis in Industrial Control Systems) was originally developed under the European Union's FP5 Research Programme. It includes real and simulated process data with artificially generated actuator faults, and was distributed to support academic research in fault detection and diagnosis.

Although the official website (http://diag.mchtr.pw.edu.pl/damadics) is no longer active, the dataset has been widely used in the scientific community. This repository contains only the specific subset of data used in the experiments described in the article and is provided exclusively for academic and reproducibility purposes.

All rights remain with the original authors and contributors of the DAMADICS benchmark. If any of the original creators request the removal of this content, it will be taken down immediately.
